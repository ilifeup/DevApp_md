# QA-01｜三 App 共用常見問題

- 共用程式碼與 Migration，**各 App 獨立資料庫各一張 `faqs` 表**，不共用資料庫。
- Flutter：公開常見問題列表，點問題展開答案；CORE-04 模組開關控制入口與 API。
- Filament：各 App 管理員新增／編輯／刪除／排序／啟停問題與答案。
- `faqs`：`id`, `question`, `answer`, `sort_order`, `is_active`, timestamps。純文字與換行、權限驗證。
- 一個只讀公開列表 API，依排序回傳啟用資料；無跨 App 讀取。
- **不做**分類、搜尋、多語、AI、附件、評分、複雜知識庫。
- 驗收：三 App 資料隔離、各自管理權限、排序與啟停、模組關閉時入口與 API 不可用、輸入安全。
