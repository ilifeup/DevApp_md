##### PA-01｜P0 完整實作規格（核心流程／資料表／API／後台／Flutter／規則／驗收）


###### 核心流程

頁面 Registry／Manifest（程式碼管理） → 驗證頁碼、路徑及元件關聯 → 原子同步兩張索引表 → 管理員在 Filament 搜尋／篩選 → 查看簡易頁面、點擊跳頁或返回 → 複製除錯資訊並搭配 PNG 截圖 → 交給 ChatGPT／Claude。Flutter 只依既有會員權限顯示目前頁碼，不讀取整份 Atlas。
PA-SYNC-01：；新增 PA-SYNC-01：Claude 大批次完成 → Registry → 驗證 → Hash 差異 → CLI 同步／跳過 → DB → Filament，失敗回滾。


###### 資料表

ui_pages：app_code、page_code（跨 App 複合唯一）、module_code、page_name、source_path、route、主要 DB/API 參照、版本／同步標記、retired。ui_page_components：ui_page_id 外鍵、component_key、type、label、field/action、db_column、target_page_code、sort_order。僅兩張核心表；不得擅增版本、截圖、Bug、Scenario 表。
PA-SYNC-01：；同步記錄 manifest_hash、last_synced_at 與 retired；頁碼複合唯一、元件鍵每頁唯一，只有兩表。


###### API

管理員端使用 Filament／Laravel 已授權的後台讀取及索引同步流程；不開放公開 Page Atlas API。Flutter 沿用現有登入／me 回應中的 can_view_page_ids 權限（若目前尚無該欄位，需在既有契約擴充），不為每頁額外呼叫 API。資料表／API 對照未經程式核實須顯示「待核對」。
PA-SYNC-01：；P0 提供 php artisan page-atlas:sync（含 --dry-run）；POST /api/internal/page-atlas/sync 僅預留，不作 P0 必開。


###### Filament 後台

獨立選單「Page Atlas 🔎」；搜尋頁碼、名稱、App、模組；頁面清單＋關鍵元件清單＋來源／DB／API 資訊；依元件資料產生約 80% 重要資訊的簡易示意圖；有 target_page_code 的按鈕可跳至另一示意頁並返回。提供一鍵複製頁碼、來源、元件、DB、API、版本及待核對事項；PNG 截圖須先驗證瀏覽器可行方案，保留手動擷取備援。僅授權管理員可進入。
PA-SYNC-01：；顯示最新同步時間、待核對項與停用頁面狀態。


###### Flutter App

正式 App 一般帳號不顯示頁碼；獲後端授權的 AdminTest 類測試帳號登入後自動顯示，不提供 App 內開關。共用 PageIdBadge 或既有 Router／Scaffold 統一掛載；SafeArea、IgnorePointer、避開返回鍵、輸入欄、播放器及底部導覽；無安全位置時可隱藏。登出／換帳號清除舊權限。App 不載入 Registry、Mock、DB/API 索引，也不額外增加專用請求。
PA-SYNC-01：；Flutter 不呼叫同步 API，也不以 JS 自動更新 DB。


###### 規則、去重

永久頁碼不可重編、不可回收；以 (app_code,page_code) 保證跨 App 唯一。Registry／Manifest 是唯一權威，資料庫僅作索引；匯入前檢查重碼、失效來源及導航目標，失敗不得部分寫入。只登記關鍵元件，不重建像素級 UI；不加 Playwright、獨立 Preview Server 或大型新依賴；頁碼不代表授權，正式 App 不顯示程式路徑／DB/API。
PA-SYNC-01：；Manifest Hash 去重、整批驗證、交易回滾、顯式停用、禁止因批次缺頁而自動刪除。


###### 驗收

① 不同 App 相同局部頁碼可正確區分、重碼拒絕；② 路由或檔名更改不重編永久頁碼；③ 後台可查詢頁面／元件／來源／DB/API，未知項標待核對；④ 簡易示意能跳頁、返回，且不執行正式寫入；⑤ 可複製完整除錯摘要，PNG 可取得或有明確可用的手動備援；⑥ 一般會員不見頁碼，授權帳號可見、不遮擋操作、登出清除；⑦ 同步失敗回滾；⑧ 未實際測試的項目不可標示通過。
PA-SYNC-01：；驗證首跑、重跑冪等、更新、停用、缺頁不誤刪、無效 Manifest 回滾、環境未就緒明示未同步。
